# FakeRoms

FakeRoms portable para RetroArch con placeholders de ROMs.

## Contenido de cada release
- **FakeRoms-win.zip**: el programa (lanzador FakeRoms.exe + Python embebido, portable).
- **playlists.zip**: las 194 playlists de RetroArch.
- **romsfake.zip**: la coleccion de placeholders romsfake.

Instalacion recomendada: **Install RetroArch FakeRoms.exe** (se monta sobre un RetroArch existente).
